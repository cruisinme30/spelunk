# Code of Conduct

This project follows the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/).
Everyone who takes part (in issues, pull requests, reviews and discussions) is expected to uphold it.

## Reporting an issue

Report unacceptable behaviour privately to the maintainer, [@cruisinme30](https://github.com/cruisinme30), via a direct
message on GitHub. Don't use a public issue. Reports are handled confidentially and get an acknowledgement within
seven days.

## Enforcement

The maintainer applies the Covenant's "Addressing and Repairing Harm" guidance. Depending on the harm, outcomes range
from a private warning, through a temporary ban from the project's spaces, to a permanent ban.
